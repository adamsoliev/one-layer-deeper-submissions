# One Layer Deeper

This repository contains research notes and a model submission for the [One Layer Deeper competition](https://onelayerdeeper.ai/).
The competition tests whether models can learn serial computation that generalizes beyond their training depth.
The [official repository](https://github.com/tilde-research/one-layer-deeper) contains the rules, evaluator, and submission instructions.

See [one-layer-deeper.md](one-layer-deeper.md) for the research notes and [`submission.py`](submission.py) for the current submission.
